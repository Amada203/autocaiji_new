# 商品价格智能采样策略方案

## 需求分析

### 背景
- 电商平台上商品价格变化趋势调研
- 需要第一时间捕捉目标商品价格变动信息
- 当前采用每日采样策略，但发现商品价格并非每天都变化

### 目标
1. **高可靠性捕获价格变化**：能尽可能第一时间捕捉到价格变化（95%~99%可靠性）
2. **最小化采样次数**：在满足高可靠性的前提下，尽量减少不必要的采样次数
3. **利用历史数据**：基于过去两年的历史价格数据制定策略

## 数据分析方法

### 1. 价格变化时间模式分析
- **周内模式**：分析价格变化是否集中在特定工作日
- **月内模式**：分析价格变化是否存在月初、月中、月末等规律
- **季节性模式**：分析价格变化是否与季节、节假日相关
- **长期趋势**：分析价格变化频率的长期变化趋势

### 2. 商品分组聚类
- 根据价格变化频率将商品分为高、中、低频变化组
- 基于价格变化模式相似性进行商品聚类
- 识别具有独特变化模式的商品

### 3. 相关性分析
- 分析不同SKU之间价格变化的时序相关性
- 识别"领先指标"SKU（价格变化通常领先于其他相关商品）
- 构建SKU价格变化相关性网络

## 技术实现方案

### 推荐模型组合

#### 1. 时间模式分析
- **Prophet模型**：处理时间序列中的长期趋势、多重季节性和节假日效应
- **自定义规则**：捕捉特定促销活动、节假日等特殊事件对价格的影响

#### 2. SKU分组聚类
- **层次聚类(Ward法)**：识别价格变化模式相似的SKU组，无需预先确定簇数
- **DBSCAN算法**：识别具有异常价格变化模式的SKU

#### 3. 相关性网络构建
- **Granger因果检验**：确定SKU间的领先-滞后关系，识别价格变化的传导关系
- **图算法**：构建高效触发网络，优化采样策略

#### 4. 变化概率预测
- **LightGBM模型**：预测特定(SKU,日期)组合的价格变化概率
  - 特征：周几、日期、月份、是否节假日、历史变化频率、相关SKU状态等
  - 输出：价格变化概率

### 模型选择理由
- **Prophet vs ARIMA**：Prophet更好处理多季节性和缺失值
- **LightGBM vs XGBoost**：更快的训练速度，更少的内存消耗
- **层次聚类 vs K-Means**：无需预先确定簇数，层次结构更具解释性
- **Granger因果检验 vs 简单相关性**：能识别因果关系方向，而非仅相关性

## 智能采样策略

### 1. 基于时间模式的差异化采样
- 在高概率变化日进行重点采样
- 在低概率变化日减少采样频率
- 节假日、促销期等特殊时期调整采样策略

### 2. 基于商品分组的差异化采样
- **高频变化SKU**：每日1-2次采样
- **中频变化SKU**：按照高概率变化时间点采样
- **低频变化SKU**：每周2-3次定期采样，加特殊时期采样

### 3. 动态触发式采样
- **哨兵SKU机制**：监控关键SKU，当其价格变动时触发相关SKU的额外采样
- **市场环境触发**：当检测到原材料价格波动、平台促销等外部因素时，提高采样频率

## 系统实现框架

### 1. 系统架构
```
数据预处理 → 时间模式提取 → SKU聚类 → 相关性网络构建 → 变化概率建模 → 采样计划生成
```

### 2. 核心组件
- **EnhancedDataProcessor**：扩展现有数据处理器，提取季节性特征，计算变化概率
- **PriceChangeProbabilityPredictor**：预测价格变化概率的机器学习模型
- **SamplingScheduleGenerator**：生成固定采样计划和动态触发规则

### 3. 算法流程
1. 使用Prophet分析每个SKU组的时间模式
2. 用层次聚类将SKU分为5-10个行为相似的组
3. 构建Granger因果网络识别关键"触发器"SKU
4. 训练LightGBM模型预测价格变化概率
5. 采用贪心算法优化采样计划，确保95-99%捕获率
