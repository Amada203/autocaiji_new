# SKU价格变动预测系统

## 配置说明
系统使用`config/database.json`作为数据库配置源。尽量简化代码。

## 项目概述
本项目旨在通过分析SKU的历史价格数据，构建二分类模型来预测商品在特定日期相较前一日是否会发生价格变动。该系统可以帮助电商平台提前预知价格变动，优化运营策略。

## 系统架构

## 核心功能
1. 数据采集与预处理
   - SKU历史价格数据清洗
   - 价格变动判断标准
     * 简单判断：与前一日价格不同即视为变动
     * 变动类型：上涨/下跌/不变
   - 新增数据列
     * price_change_flag：价格是否变动（0/1）
     * price_change_type：变动类型（up/down/unchanged）
     * price_change_amount：变动金额（当前价格 - 前一日价格）
     * price_change_ratio：变动比例（变动金额/前一日价格）
     * price_change_direction：变动方向（1上涨/-1下跌/0不变）
     * price_change_streak：连续变动天数
   - 异常值检测与处理
     * 缺失值处理
     * 重复数据处理
   - 数据标准化
     * 时间特征编码
     * 类别特征编码

2. 特征工程
   - 时间特征
     * 星期几（是否周末）
     * 是否节假日
     * 是否促销日
     * 距离上次价格变动的天数
     * 距离下次价格变动的天数
   - 价格相关特征
     * 前N天价格变动频率
     * 价格变动幅度统计
     * 价格变动间隔
     * 价格变动趋势（上升/下降/震荡）
     * 价格变动周期特征
   - 商品特征
     * 商品类别
     * 商品生命周期阶段
     * 历史销量
     * 价格敏感度指标
   - 交叉特征
     * 时间与价格变动的交互特征
     * 商品类别与时间特征的交互
     * 价格变动与销量的关系特征

3. 模型开发
   - 基础模型
     * 逻辑回归（基准模型）
     * 随机森林
   - 高级模型
     * LightGBM
     * XGBoost
   - 模型评估与优化
     * 类别不平衡处理
     * 模型集成
     * 阈值优化

4. 预测服务
   - RESTful API接口
   - 批量预测功能
   - 预测结果可视化
